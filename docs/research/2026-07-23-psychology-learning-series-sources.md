# Psychology Learning Series Source Review

This human-review note supports the closed starter curriculum
`after_work_rumination`. It is deliberately not loaded into prompts,
checkpoints, generated artifacts, OpenClaw responses, or reader-visible posts.
Runtime receipts retain only the opaque identifiers below.

## Review boundary

- The catalog is a fixed educational aid, not a diagnostic, treatment, crisis,
  medication, or self-test flow.
- Each lesson keeps one concrete scene, one approved concept, a small bounded
  exercise, an applicability limit, and a professional-help boundary.
- Adding or revising a lesson requires a new human review, a catalog version
  change, and updates to the opaque receipt mapping. It must not be done by
  passing source text or a URL at runtime.
