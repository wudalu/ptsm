# 现代心理困境观察 Reflection

检查这条内容是否满足：

1. 是否从一个具体生活场景切入？
2. 标题是否只写具体瞬间、动作或脑内小剧场，没有提前暴露心理机制？
3. 是否解释了一个心理机制，而不是只共情或只吐槽？
4. 概念名是否放在生活瞬间之后，且最多出现一次？
5. 是否避免“不是你太敏感/不是你想太多/这不是 xxx”这类固定破梗句？
6. 是否给了自然可保存的小工具、可存句或低风险小动作，例如事实/猜测/下一步三栏、5分钟计时器、边界句模板、消息草稿？
7. 是否有角色认领、A/B 阵营或填空式评论提示？
8. 是否包含“专业帮助”边界提醒，且放在实用工具之后？
9. 是否避免诊断化表达、治疗承诺、药物建议和危机处理替代？
10. 标签是否包含 `#心理学`？
11. 是否把爱你老己、三明治拒绝法、丝瓜汤式沟通或 AI 陪伴边界这类热点转成低风险工具，而不是直接蹭词？
12. 是否温暖、像真人、有具体处境，而不是格式化心理课？
13. 如果是亲密关系等待消息、分手脑补、复合挽留或猫归谁场景，是否避免写成职场协作、处理时间、优先级或“我现在不方便”的工作式回复模板？
14. 正文是否在 200-380 字之间，并用 2-4 个短拍保留微场景、轻量机制、低风险动作与自然认领入口？
15. 如果 runtime context 包含 `# Psychology Learning Series Contract`，是否完整保留该课的系列标记、概念、学习目标、批准解释、适用场景、微练习、范围边界、专业帮助边界和评论提示，且没有加入课外心理学主张、来源、诊断或疗效承诺？
16. 普通心理学轮播是否在同一草稿里根据内容需要给出 1-18 张同主题语义卡，第一页为封面钩子，后续按需承接具体场景、轻量机制、可保存工具、边界和评论入口，而不是预设页数或机械切正文；图片可见字段是否已去掉 emoji，超过 18 页时是否停止并要求缩短或拆帖？
17. `slides` 是否按 1 开始连续排序、ID 唯一稳定、每页只有允许字段和短行，并且没有标签、URL、来源定位、诊断、治疗承诺、药物建议或提示词泄漏？学习专题的页面是否仍由目录 exact gate 全权决定？

如果缺少第 2、3、6、7、8、9、10、13、14 项，普通轮播的第 16、17 项不通过，或第 15、17 项在学习专题中不通过，要求重写。
