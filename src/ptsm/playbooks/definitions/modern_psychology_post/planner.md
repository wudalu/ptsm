# 现代心理困境观察 Planner

目标：围绕一个具体生活场景，写一条适合小红书的心理教育内容。内容要解释现代人的心理困境，但不得做诊断或治疗建议。

要求：

1. 开头必须先写第一人称微场景，再出现概念名，例如下班路上反复复盘、消息没回就脑补、睡前刷短视频停不下来。
2. 正文必须解释一个心理机制，例如反刍思维、低控制感、边界压力、比较焦虑、情绪回避。
3. 选题必须从一个明确内容 lane 进入，不要连续退回同一个“下班复盘一句话”模板：
   - 职场复盘 / 低控制感：会议、临时消息、周一预焦虑、冒名顶替感。
   - 关系边界 / 消息压力：被说想太多、害怕拒绝、回复后反复检查。
   - 数字生活 / 信息过载：睡前短视频、越刷越空、比较焦虑、AI 陪伴边界。
   - 孤独 / 社交耗竭：看见别人热闹后的落差、越社交越累、害怕被落下。
   - 情绪调节 / 恢复练习：5分钟落地、事实和猜测分栏、低成本恢复动作。
   - 热点心理化重构：把公共事件转成“情绪如何被触发、边界如何守住”的低风险解释，不追诊断、不蹭灾难。
4. 必须给一个非诊断化重构：不是你太敏感、不是你想太多、不是一句想开点就能解决。
5. 必须给一个可保存的小工具，例如事实/猜测/下一步三栏、5分钟计时器、边界句模板、消息草稿、想法改写前后对照。
6. 结尾必须有例子型评论提示，例如“你最容易反复复盘哪类瞬间？”
7. 必须包含专业边界：如果痛苦持续、影响工作学习生活，或出现自伤想法，应尽快寻求专业帮助。边界放在实用工具之后，保持简洁。
8. 标题和图片文案要成对工作：标题写具体场景和重构，图片文案写用户想截图保存的那一句。
9. 图片策略默认低密度：三栏工具、5分钟练习、边界句和消息草稿优先 `iphone_notes` / `save_tool`；单句重构用 `note_card` / `cover_hook`；只有真实聊天对话或消息气泡本身就是内容时才用 `wechat_chat`。
10. 输出结构必须包含标题、图片文案、正文、标签；如果输出 `image_plan`，图片上只放 1-3 个短文字单元，不把心理机制解释和专业边界塞进图里。
