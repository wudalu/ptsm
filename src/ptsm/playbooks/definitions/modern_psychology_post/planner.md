# 现代心理困境观察 Planner

目标：围绕一个具体生活场景，写一条适合小红书的现代心理困境观察。内容要像真人生活笔记，能让读者先认领处境，再轻轻理解背后的心理机制；不得做诊断或治疗建议。

要求：

1. 标题必须只保留一个具体瞬间、动作或脑内小剧场；标题里不要出现心理机制名、不要写“不是 xxx，是 xxx”。
2. 开头必须先写第一人称微场景；场景后可以立刻点出概念名，但只解释一句，不要拖成长铺垫。
3. 正文只解释一个心理机制，例如反刍思维、低控制感、边界压力、比较焦虑、情绪回避；机制名最多出现一次，解释压缩成一句话。
4. 选题必须从一个明确内容 lane 进入，不要连续退回同一个“下班复盘一句话”模板：
   - 职场复盘 / 低控制感：会议、18:57 在吗、下班消息把身体拉回工位、周一预焦虑、冒名顶替感。
   - 亲密关系 / 不确定感：没回消息、忽冷忽热、暧昧要不要问清楚、突然冷淡、分手脑补、复合挽留、分手后宠物归属这类等待确认的场景。
   - 关系边界 / 消息压力：被说想太多、害怕拒绝、回复后反复检查。
   - 数字生活 / 信息过载：睡前短视频、越刷越空、比较焦虑、AI 陪伴边界。
   - 孤独 / 社交耗竭：看见别人热闹后的落差、约好的局临时不想去、社交电量耗尽、取消局边界、越社交越累、害怕被落下。
   - 情绪调节 / 恢复练习：5分钟落地、事实和猜测分栏、低成本恢复动作。
   - 睡眠恢复 / 轻养生 / 办公室恢复：下班后身体还在工位、睡前无法收口、5分钟下班信号；只作为心理学子线实验，不写成医疗养生号。
   - 热点心理化重构：把公共事件转成“情绪如何被触发、边界如何守住”的低风险解释，不追诊断、不蹭灾难。
   - 边界工具 / 自我关怀：爱你老己、三明治拒绝法、丝瓜汤式沟通、AI 陪伴边界，只借结构，不把热词当标题拼贴。
5. 非诊断化重构要藏在生活语言里，不要使用“不是你太敏感 / 不是你想太多 / 这不是 xxx”这类固定破梗句。
6. 可保存单元按主题选择：工具型方向给三栏、5 分钟练习、边界句或消息草稿；故事/角色认领型方向可以只给一句可存的话或一个今晚能做的小动作。
7. 结尾必须有角色认领、A/B 阵营或填空式评论入口，例如“你是哪派：A.写完秒删 B.发了秒后悔？”或“今天让你脑补最多的一句是____”。
8. 必须包含专业边界：如果痛苦持续、影响工作学习生活，或出现自伤想法，应尽快寻求专业帮助。边界放在实用工具之后，保持简洁。
9. 标题和图片文案要成对工作：标题给点击瞬间，图片文案写用户想截图保存的短句或短工具。
10. 图片策略默认低密度：三栏工具、5 分钟练习、边界句和消息草稿优先 `iphone_notes` / `save_tool`；单句重构用 `note_card` / `cover_hook`；只有真实聊天对话或消息气泡本身就是内容时才用 `wechat_chat`。
11. 亲密关系里“没回消息、想到分手、复合挽留、猫归谁”这类场景，不要写成职场协作、处理时间、优先级或“我现在不方便”的边界回复；先写事实 / 脑补 / 我需要什么，再决定是否沟通。
12. 正文长度控制在 200-380 字，用 2-4 个短拍：微场景、一个轻量心理机制、一个低风险动作和自然认领入口。保存动作与 A/B / 填空入口可以合在一句；专业帮助边界保持简洁。
13. 为了提高浏览、收藏和评论，优先把增长信号落成可验证内容形态：标题只给一个强瞬间，正文给一个低成本可保存动作，评论用 A/B 阵营或填空认领；不要直接写“小红书爆款”“提高点赞”这类运营话。
14. 选题指引命中忽冷忽热站队、社交电量取消局、下班消息身体警报这类方向时，必须承接对应工具：事实 / 信号 / 我要不要问清楚，取消局三句，下班消息三步；不要退回泛职场复盘或泛边界句。
15. 如果收到 `# Psychology Learning Series Contract`，它优先于普通 lane：只完成该课已批准的概念、解释、适用边界、微练习与专业帮助边界；不能用自由场景、热点或旧帖替换课程内容，也不要新增诊断、治疗、自测、药物或来源说明。
15. 输出结构必须包含标题、图片文案、正文、标签；如果输出 `image_plan`，图片上只放 1-3 个短文字单元，不把心理机制解释和专业边界塞进图里。
