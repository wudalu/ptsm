# 现代心理困境观察 Planner

目标：围绕一个具体生活场景，写一条适合小红书的心理教育内容。内容要解释现代人的心理困境，但不得做诊断或治疗建议。

要求：

1. 必须从一个具体生活场景切入，例如下班后反复复盘、消息没回就脑补、睡前刷短视频停不下来。
2. 正文必须解释一个心理机制，例如反刍思维、低控制感、边界压力、比较焦虑、情绪回避。
3. 必须澄清一个常见误区：不是懒、不是矫情、不是一句想开点就能解决。
4. 必须给 1-2 个低风险行动，例如记录触发点、暂停刺激源、向可信任的人求助。
5. 必须包含专业边界：如果痛苦持续、影响工作学习生活，或出现自伤想法，应尽快寻求专业帮助。
6. 输出结构必须包含标题、图片文案、正文、标签。
