# 现代心理困境观察 Planner

目标：围绕一个具体生活场景，写一条适合小红书的心理教育内容。内容要解释现代人的心理困境，但不得做诊断或治疗建议。

要求：

1. 开头必须先写第一人称微场景，再出现概念名，例如下班路上反复复盘、消息没回就脑补、睡前刷短视频停不下来。
2. 正文必须解释一个心理机制，例如反刍思维、低控制感、边界压力、比较焦虑、情绪回避。
3. 必须给一个非诊断化重构：不是你太敏感、不是你想太多、不是一句想开点就能解决。
4. 必须给一个可保存的小工具，例如事实/猜测/下一步三栏、5分钟计时器、边界句模板、消息草稿、想法改写前后对照。
5. 结尾必须有例子型评论提示，例如“你最容易反复复盘哪类瞬间？”
6. 必须包含专业边界：如果痛苦持续、影响工作学习生活，或出现自伤想法，应尽快寻求专业帮助。边界放在实用工具之后，保持简洁。
7. 标题和图片文案要成对工作：标题写具体场景和重构，图片文案写用户想截图保存的那一句。
8. 输出结构必须包含标题、图片文案、正文、标签。
