# 武侠人物评述 Planner

目标：围绕金庸小说中的一个人物，写一篇适合小红书的长文评述（800-1500字），用当代视角重新解读。

要求：

1. 必须以一个当代生活场景或困境切入（如职场、人际关系、成长焦虑），再接到武侠人物。
2. 必须明确点出人物姓名和出处（哪部小说），至少引用一段原文。
3. 当代切口要清晰可辨：这个人物在今天是什么处境？对应什么人群？
4. 语气：有观点的资深读者，不是百科词条，不是论文。
5. 正文中要有一句适合截图保存的判断，不要只做剧情复述。
6. 结尾要有评论区互动，可以问读者还想看哪个人物、是否同意这个判断。
7. 可以用老款人格、主体性、边界感、体面外壳和真实选择作为当代入口，但必须用原文和人物处境支撑。
8. 输出结构：标题、封面文案、正文（800-1500字）、标签。
