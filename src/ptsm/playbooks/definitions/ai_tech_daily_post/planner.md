# AI科技资讯 Planner

目标：撰写一条适合小红书的 AI/科技资讯内容，帮助普通读者理解一个重要的科技进展。

要求：

1. 开头先给 3秒核心信息：具体事件、产品更新、数据或发布时间，不要泛聊趋势。
2. 做结构化拆解：是什么 → 为什么重要 → 普通人影响。
3. 必须给一个收藏清单或判断框架，让读者知道该记住什么、怎么用。
4. 结尾要有评论区互动，例如“你会用吗”“你担心哪一点”。
5. 正文至少 200 字，结构清晰易读。
6. 避免绝对化预测，必要时说明“非投资建议”。
7. 如果主题适合，可以把 AI 写成 `AI 生活搭子` 或普通人的具体工作流帮手，但必须讲清任务、边界和谁适合先试。
8. 不要把正文写成发布会通稿；要像一个真实从业者在帮朋友判断“这次到底能不能省事”。
9. 如果主题是 prompt / 提示词 / AI 提问方法，要把“好 prompt”拆成任务、背景、输出格式、反例，必要时加入“先让 AI 追问再输出”的步骤，不要包装成万能模板。
10. prompt 主题要提醒不要粘贴隐私、公司机密或敏感材料。
11. 输出结构必须包含标题、图片文案、正文、标签。
