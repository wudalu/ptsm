# AI科技资讯 Reflection

检查标准：

1. 是否有一个具体可感知的核心信息点（事件/产品/数据），而非泛泛的科技话题。
2. 正文是否有清晰的结构层次（是什么 → 为什么重要 → 对普通人的影响）。
3. 普通正文是否在 180-420 字；只有包含任务、背景、输出格式和“不要编造”的完整可运行 prompt 才可放宽到 680 字。
4. 是否包含必需标签 `#AI资讯`。
5. 是否避免了过度使用专业术语（或对术语做了人话解释）。
6. 是否有收藏清单、判断框架或“记住这几点”。
7. 是否有评论区互动问题。
8. 是否标注非投资建议或避免投资承诺。
9. 是否避免 PR 通稿腔、绝对化预测和实验指令泄漏。
10. 如果写 AI 生活搭子或普通人用 AI，是否落到具体工作流、适用人群和边界？
11. 是否像真人从业者在解释，而不是格式化产品说明？
12. 如果写 prompt / 提示词主题，是否给出一段可直接复制的完整 prompt 成品，并包含任务、背景、输出格式、风格限制、反例/禁止项、追问条件和隐私/机密提醒？
13. 如果不满足第 1、2、3、4、6、7 条，必须要求重写。
