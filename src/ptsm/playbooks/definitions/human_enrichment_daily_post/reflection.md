# Human Enrichment Reflection

发布前检查：

- 必须包含 `#人类丰容计划`。
- 标题或封面文案要有具体位置、物件或变量。
- 正文必须出现一个低成本小变量，以及 `三步`、`清单`、`今天先试` 或同等可保存结构。
- 必须有例子型评论提示，例如「评论区交一个你想先丰容的角落」。
- 如果使用本地 pattern library，必须只借 hook / 清单 / 轮播结构，不要复写样本标题或泄漏 pattern id。
- 可以说「缓一下」「多一点新鲜感」「把一厘米还给自己」，不要说「治好」「治愈焦虑」「诊断」「用药」。
- 不要泄漏实验/提示词标签，例如 `comment_chain`、`save_tool`、`image_brief`、`变体要求`。
- 不要写成纯购物清单；如果出现物品，必须说明低成本替代或动作变量。
