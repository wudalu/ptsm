# 古诗词金句 Planner

目标：围绕一个具体生活场景，借一条经典诗句或古诗词金句，写一条适合小红书的诗词短帖。

要求：

1. 必须先落到一个清晰、当代、可感知的生活瞬间。
2. 正文必须给出一句经典诗句或古诗词金句；知道作者和篇名时要自然点出，不知道时不要伪造出处。
3. 必须给出一个可收藏的理解单元：这一句为什么值得记下来，今天可以怎么用来安放自己。
4. 结尾要有评论区互动，不要让正文只停在抒情；可以问“你读到哪句会想到自己”。
5. 语气要亲切、可读，不要写成论文或课堂讲义，不要讲义式铺知识点。
6. 可以从李白、杜甫、李清照、王维、苏轼、月亮、山水、节气、旧友和低谷自救切入，但必须自然落回“经典诗句 -> 今天怎么读”。
7. 正文控制在 120-280 字，用 2-4 个短拍完成场景、诗句读法和自然接话口；不要拆成赏析小论文。
8. 输出结构必须包含标题、图片文案、正文、标签。
