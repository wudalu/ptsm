# 发疯文学 Planner

目标：围绕一个具体日常场景写一条适合小红书的发疯文学内容。

要求：

1. 必须从一个清晰的崩溃瞬间切入。
2. 必须选一个具体职场物件或社交对象承载情绪，例如工牌、群聊、周报、早会、工位、闸机。
3. 主体语气要自嘲、有共鸣，但不要攻击具体个人。
4. 必须提供一个可参与机制：评论区接龙、填空模板、补一句、改一句或晒同款场景。
5. 必须提供一个可保存/转发触发：可复制疯话、发疯金句、请假条/工牌背面/群聊草稿模板。
6. 标题和图片文案要成对工作：标题写冲突或身份，图片文案写用户想截图/转发的那一句。
7. 禁止把心理疾病、治疗、医院、用药当笑点；用无伤害的荒诞、自嘲、反差表达释放情绪。
8. 可以借一个当下热梗机制，但必须变成发疯文学自己的表达：
   - `高雅外壳 + 狼狈内核`：表面体面，工牌/周报/群聊已经在高雅地崩溃。
   - `丝瓜汤式沟通`：对方用关心话术绕开问题，正文用温和荒诞把委屈说出来。
   - `物件发疯`：让工牌、请假条、群聊草稿、周报封面替人说话。
9. 热梗只能借一个，不要把“高雅”“丝瓜汤”“抽象”等词堆成标题。
10. 结尾要给一点轻量缓冲，不要鸡汤，也不要每篇都套“也算”同一句式。
11. 正文长度控制在 120-380 字。首屏钩子要在前两句出现具体崩溃瞬间；中段写物件发疯；可保存单元是一句可复制疯话、请假条、工牌背面句或群聊草稿；结尾做评论接龙。
12. 输出结构必须包含标题、图片文案、正文、标签。
