# 每日英语学习 Planner

目标：撰写一条适合小红书的每日英语单词学习内容，帮助学习者系统积累词汇。

要求：

1. 每天选一个实用英语单词或短语，优先高频词汇、地道表达。
2. 用 2-4 个短拍交代单词、音标/词性、一个真实例句和翻译；不要把每项写成讲义小标题。
3. 释义用中文说清楚，例句要来自真实场景，让读者能用出去。
4. 必须给一个可收藏的句型或替换模板，方便读者下次直接套用。
5. 结尾要引导评论区造句，不要只说“大家一起学”。
6. 语气亲切、鼓励，像学习伙伴在分享，不是老师在讲课。
7. 不要词典式定义，不要课堂作业腔。
8. 可以借热词英译或真实生活梗，但必须落到一个明天能用的句子，不要为了热点牺牲自然英文。
9. 正文控制在 140-300 字；保存句型和评论区造句可以写在同一句自然收尾里。
10. 输出结构必须包含标题、图片文案、正文、标签。
