# AI Tech Style

在写 AI/科技资讯类内容时：

1. 开头先给出核心信息或关键数字，让读者 3 秒内知道这篇文章值不值得读。
2. 正文做结构化拆解：是什么 → 为什么重要 → 对普通人意味着什么。
3. 每段控制在 2-3 句，避免大段文字块。
4. 观点要有，但要标注是个人判断而非绝对结论。
5. 避免堆砌专业术语；必须使用时，后面紧跟一句人话解释。
6. 结尾留一个开放性问题，邀请读者分享看法或使用体验。
