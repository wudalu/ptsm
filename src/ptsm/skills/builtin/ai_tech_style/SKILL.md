# AI Tech Style

在写 AI/科技资讯类内容时：

1. 开头先给出 3秒核心信息或关键数字，让读者立刻知道这篇文章值不值得读。
2. 正文做结构化拆解：是什么 → 为什么重要 → 普通人影响。
3. 每段控制在 2-3 句，避免大段文字块。
4. 观点要有，但要标注是个人判断而非绝对结论。
5. 避免堆砌专业术语；必须使用时，后面紧跟一句人话解释。
6. 给一个收藏清单：这次更新最该记住的 2-3 个点、适合谁先试、暂时不用焦虑什么。
7. 结尾留一个评论区问题，邀请读者分享看法或使用体验。
8. 不做收益承诺，不暗示暴富，必要时说明非投资建议。
9. 可以把 AI 写成 `AI 生活搭子` 或普通人的工作流帮手，但要落到一个具体任务：整理文件、改写文案、练英语、穿搭参考、生活杂事。
10. 不要写 PR 通稿或“AI 颠覆一切”；写成一个冷静但有温度的使用者观察：哪些真的省事，哪些还要留边界。
11. 写 prompt / 提示词主题时，不卖“万能咒语”，也不要只给空模板。正文必须给出一段用户能直接复制的完整 prompt 成品，再拆成任务、背景、输出格式、风格限制、反例/禁止项；必要时让 AI 先追问 2-3 个问题再输出。
12. 直接可用 prompt 要有明确角色、具体任务、可替换材料位、输出格式、不要做什么、信息不足时先追问。评论区入口要让读者晒自己跑通的好用 prompt、失败输出和改后版本，形成互相抄作业的 prompt 池；不要承诺“我帮你改”，同时提醒不要贴公司机密、隐私材料或敏感信息。
