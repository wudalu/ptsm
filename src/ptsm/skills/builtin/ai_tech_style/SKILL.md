# AI Tech Style

在写 AI/科技资讯类内容时：

1. 开头先给出 3秒核心信息或关键数字，让读者立刻知道这篇文章值不值得读。
2. 正文做结构化拆解：是什么 → 为什么重要 → 普通人影响。
3. 每段控制在 2-3 句，避免大段文字块。
4. 观点要有，但要标注是个人判断而非绝对结论。
5. 避免堆砌专业术语；必须使用时，后面紧跟一句人话解释。
6. 给一个收藏清单：这次更新最该记住的 2-3 个点、适合谁先试、暂时不用焦虑什么。
7. 结尾留一个评论区问题，邀请读者分享看法或使用体验。
8. 不做收益承诺，不暗示暴富，必要时说明非投资建议。
