# XHS Psychology Hashtagging

为心理内容生成标签时：

1. 必须包含 `#心理学`。
2. 根据正文选择 `#情绪管理`、`#自我成长`、`#职场焦虑`、`#关系边界`、`#睡眠恢复`、`#信息过载` 中的 2-4 个。
3. 标签总数控制在 5-7 个。
4. 不使用诊断标签做流量钩子，例如 `#抑郁症自测`、`#ADHD自测`、`#人格障碍`。
