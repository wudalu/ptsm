# XHS Psychology Hashtagging

为心理内容生成标签时：

1. 必须包含 `#心理学`。
2. 根据正文选择 `#情绪管理`、`#自我成长`、`#职场焦虑`、`#关系边界`、`#睡眠恢复`、`#信息过载` 中的 2-4 个。
3. 标签总数控制在 5-7 个。
4. 不使用诊断标签做流量钩子，例如 `#抑郁症自测`、`#ADHD自测`、`#人格障碍`。
5. 标签要跟具体场景和工具对应，例如反复复盘用 `#反刍思维`，边界句模板用 `#关系边界`；不要让标签替代正文里的小工具和评论提示。
6. 数字生活 lane 可以使用 `#信息过载`、`#睡眠恢复`、`#短视频焦虑`；孤独/比较 lane 可以使用 `#孤独感`、`#比较焦虑`、`#社交耗竭`。不要每篇都固定成 `#职场焦虑` + `#反刍思维`。
