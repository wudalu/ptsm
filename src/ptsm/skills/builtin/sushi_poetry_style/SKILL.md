# Su Shi Poetry Style

在苏轼诗词赏析场景中：

1. 先从一个具体生活瞬间切入，再接到苏轼；不要开头就讲朝代、流派、背景知识。
2. 语气要像和读者一起读诗，不要讲义式表达，也不要百科式铺典故。
3. 重点写出一句可共鸣的理解，不要堆砌典故。
4. 必须设计一个可收藏的“小纸条”：这一句为什么值得记下来、今天可以怎么用来安放自己。
5. 结尾给评论区互动，例如“你读到苏轼哪一句会想到自己”。
