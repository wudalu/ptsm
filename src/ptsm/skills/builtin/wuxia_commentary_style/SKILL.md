# Wuxia Commentary Style

在武侠人物评述长文中：

1. 每篇只选一个当代切口（职场、亲密关系、边缘感、成长焦虑...）。
2. 至少引用一段原文——精确到句，不要含糊其辞。
3. 语气：像一个读过很多但愿意好好说话的老读者，不是老师。
4. 让一个没读过武侠的人也能被这个人物触动。
5. 正文里要有一句能截图保存的判断，不要只复述剧情。
6. 收尾要有金句感，并给评论区留下讨论入口：还想看谁、同不同意这个人物判断。
7. 可以用 `老款人格`、主体性、边界感、体面外壳和真实选择作为入口，但必须用原文和人物处境撑住判断。
8. 语气要像一个温暖但有锋芒的老读者，不要把人物写成 PPT 标签，也不要为了热词牺牲复杂性。
