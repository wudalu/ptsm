# Wuxia Commentary Style

在武侠人物评述长文中：

1. 每篇只选一个当代视角切口（职场、亲密关系、边缘感、成长焦虑...）。
2. 至少引用一段原文——精确到句，不要含糊其辞。
3. 语气：像一个读过很多但愿意好好说话的老读者，不是老师。
4. 让一个没读过武侠的人也能被这个人物触动。
5. 收尾要有金句感——让人想截图转发的那种。
