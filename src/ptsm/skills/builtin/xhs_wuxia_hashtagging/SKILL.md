# XHS Wuxia Hashtagging

在武侠人物评述帖子中：

1. 必须包含领域标签 `#金庸` 或 `#古龙`。
2. 包含人物名标签：`#令狐冲`、`#黄蓉` 等。
3. 包含当代视角标签：`#职场隐喻`、`#女性成长`、`#边缘人格` 等。
4. 补充 1-2 个发现类标签：`#武侠`、`#读书笔记`、`#人物评述`。
5. 共 5-7 个标签，像人写的，不像SEO堆砌。
