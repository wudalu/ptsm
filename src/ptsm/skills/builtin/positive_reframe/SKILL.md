# Positive Reframe

当文案只有负面宣泄时：

1. 保留吐槽主线。
2. 最后一句给一点轻量缓冲，可以用“也算”“至少”“还能”这类词，但不要把它们当固定结尾模板。
3. 优先把缓冲落到具体动作上：先摘工牌、先关群聊、先把周报合上、今晚先不回工位。
4. 不要鸡汤，不要上价值，不要把痛苦包装成“应该感恩”。
