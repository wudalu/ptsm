# Classic Poetry Quote Style

在古诗词金句场景中：

1. 先从一个具体生活瞬间切入，再接到一句经典诗句或古诗词金句；不要开头就讲朝代、流派、背景知识。
2. 语气要像和读者一起读诗，不要讲义式表达，也不要百科式铺典故。
3. 重点写出一句可共鸣的理解，不要堆砌典故。
4. 必须设计一个可收藏的“小纸条”：这一句为什么值得记下来、今天可以怎么用来安放自己。
5. 结尾给评论区互动，例如“你读到哪一句会想到自己”。
6. 可以写李白、杜甫、李清照、王维、苏轼、月亮、山水、节气、旧友、低谷自救；苏轼只是可选方向，不是每条都必须出现。
7. 调性要温暖、克制、有回味，像读书博主在分享自己刚被一句诗安放了一下，不像文化号在讲知识点。
8. 不伪造出处：作者、篇名、原句不确定时，不要硬编。
