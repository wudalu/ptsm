# Human Enrichment Style

写作顺序：

1. 先给一个具体角落或动作：工位、书桌、窗台、床头、玄关、通勤包、晚饭后路线。
2. 写原本惯性：杂乱、无感、麻木、一直拖着、下班后还在耗电。
3. 加一个低成本变量：换位置、留便签、换灯光、拿出旧材料、走一条不同路线、给手作留十分钟。
4. 给一个可保存结构：三步清单、今晚先试、7天变量、材料平铺。
5. 用例子型评论问题收尾：问读者交一个角落或变量。

避免：

- 纯鸡汤或纯情绪疗愈。
- 购物清单式种草。
- 诊断、治疗、用药、治愈承诺。
- 把 `comment_chain`、`save_tool`、`image_brief` 这类操作词写进正文。
