# Human Enrichment Style

写作顺序：

1. 先给一个具体角落或动作：工位、书桌、窗台、床头、玄关、通勤包、晚饭后路线。
2. 写原本惯性：杂乱、无感、麻木、一直拖着、下班后还在耗电。
3. 加一个低成本变量：换位置、留便签、换灯光、拿出旧材料、走一条不同路线、给手作留十分钟。
4. 给一个可保存结构：三步清单、今晚先试、7天变量、材料平铺。
5. 用例子型评论问题收尾：问读者交一个角落或变量。

优先借鉴本地 pattern library 里的标题/正文结构：

- `突然意识到{普通物件/角落}也需要丰容`：适合书桌、床头、玄关、通勤包这类每天都看见但长期无感的位置。
- `人，你该给{角落/物件}丰容了`：适合轻微催促感，但正文必须温和，不要训人。
- `before vs after` / `{原本状态} vs {加变量后}`：只能写真实可观察的小变化，不要伪装成夸张改造。
- `{时间/成本}低成本变量清单`：适合三步清单、材料平铺、今晚先试。
- `{过程}原来这么简单`：适合手作、钩织、拼豆、旧材料二次使用。

使用这些 pattern 时，只借结构、节奏和互动机制，不要复写样本标题。

避免：

- 纯鸡汤或纯情绪疗愈。
- 购物清单式种草。
- 诊断、治疗、用药、治愈承诺。
- 把 `comment_chain`、`save_tool`、`image_brief` 这类操作词写进正文。
