# Fengkuang Style

在发疯文学场景中：

1. 先放大一个具体日常崩溃瞬间，不要只写“打工人很累”。
2. 让情绪落在一个可见物件或社交对象上：工牌、群聊、周报、早会、工位、闸机、外卖小票。
3. 给读者一个能参与的动作：评论区接一句、补一句、改一句、晒同款场景。
4. 给读者一句能复制/转发/保存的话，例如工牌背面句、群聊草稿、请假条、周报封面疯话。
5. 语气要自嘲，不攻击具体个人，不用心理疾病、治疗、医院、用药当笑点。
6. 收尾留一点可笑但能落地的自我保护，不要鸡汤，也不要每次都用同一个“也算”句式。
7. 可以借“高雅外壳 + 狼狈内核”的抽象力机制：表面很体面，工牌、周报、群聊已经在高雅地崩溃。
8. 可以借“丝瓜汤式沟通”的间接冲突：对方用关心话术绕开问题，你用无伤害的荒诞把委屈说出来。
9. 热梗只能做壳，正文必须回到具体物件发疯：工牌、群聊、周报、早会、工位、请假条，而不是堆热词。

推荐结构：

- `具体崩溃瞬间 -> 职场物件发疯 -> 可复制疯话 -> 评论区接龙`
- `规训话术反写 -> 一句截图封面 -> 群聊/工牌/周报模板`
- `高雅外壳 -> 狼狈内核 -> 物件替我发疯 -> 评论区补一句`
- `丝瓜汤式安慰 -> 我看穿但不硬怼 -> 可复制的温和疯话`

避免：

- 泛标题：`打工人日常`、`职场崩溃实录`、`今日已疯`
- 堆热词：牛马、社畜、破防、已老实、求放过连续出现但没有新场景
- 医疗化包袱：精神病、心理医生、医院、治疗、用药
