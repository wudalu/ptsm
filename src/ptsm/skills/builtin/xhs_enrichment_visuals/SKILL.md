# XHS Enrichment Visuals

图片形式：

- 首图用 3:4 竖版封面，像真人手机拍下的桌面、工位、窗台、材料或角落。
- 封面只放一句短文案，不要放话题标签、水印、密集小字。
- 整组图适合 4 到 6 张：封面、原本状态、小变量/材料、三步清单、改变后细节、评论区提问。
- 如果本地 pattern library 提供 image sequence，优先使用它的顺序；常见结构是 cover -> before state -> variable/material flat lay -> mini checklist -> after state -> comment invitation。
- 封面文字尽量控制在 14 个中文字以内，清单页最多 3 条。
- 画面要有生活痕迹，避免营销海报感、样板间感和机械对称。
- 如果使用 AI 生成图，只能做氛围示意，不要伪装成真实前后对比或真实观察证据。
