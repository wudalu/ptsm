# XHS Trend Scan

热点扫描只提供一个可写切口，不是可以照抄的稿子。

1. 普通 playbook 运行只使用 planner 已注入的上下文，不要自行检索或补造实时信息。只有用户明确要求新鲜选题研究时，运行时才启动 Topic Radar，默认扫描 8 个平台：小红书、微博、抖音、知乎、B 站、今日头条、豆瓣、少数派。
2. 有新鲜研究上下文时，只从有证据支撑的推荐角度中选 1 个，并以已验证的事件簇为边界。推荐已完成新颖性筛选、同事件去重和近期角度冷却；同一事件不要拆成多条热点或多组切口。
3. playbook 已限定主题时，保留主题主线，只补一个更具体的切口；把角度改写成自己的具体场景、动作、情绪和自然的互动问题。
4. 不要复写原始标题、作者、链接或样本措辞；不假装看到上下文以外的实时结果，也不要把有限证据夸成“全网都在讨论”。
5. 明确的新鲜研究扫描为证据不足或没有可用推荐角度时，运行会在生成前停止并返回诊断；先修复平台或关键词，或由用户明确改走本地主题包。不要把它写成新鲜热点，也不要把常青表达冒充为本次扫描结论。普通运行没有研究上下文时，才继续使用本地主题包或常青表达。
