# Daily English Style

在写每日英语学习内容时：

1. 选词优先选高频实用词汇和地道表达，不选生僻词。
2. 结构：单词 → 音标 → 词性 → 中文释义 → 英文例句 → 中文翻译 → 练习引导。
3. 例句要来自真实日常场景（对话、职场、社交媒体），不要教科书例句。
4. 中文释义接地气，用大家能听懂的话，不要词典式定义。
5. 语气像学习伙伴在分享心得，有陪伴感，不要说教。
6. 结尾引导读者自己造句，增强参与感。
