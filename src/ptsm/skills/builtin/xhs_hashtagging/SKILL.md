# XHS Hashtagging

在小红书文案中：

1. 至少包含一个领域标签和两个场景标签。
2. 标签要贴近日常表达，不要像 SEO 关键词堆砌。
3. 发疯文学方向优先包含 `#发疯文学`。
4. 场景标签优先跟正文物件和现场一致，例如 `#工牌文学`、`#职场发疯实录`、`#通勤崩溃实录`、`#会议崩溃实录`。
5. 不要用标签替代正文机制；正文里仍要有评论区接龙、可复制句或模板。
