# Psychology Style

写现代心理困境观察内容时：

1. 每篇只解释一个心理机制，例如反刍思维、低控制感、边界压力、情绪回避、比较焦虑。
2. 结构遵循：具体场景 -> 心理机制 -> 误区澄清 -> 低风险行动 -> 专业边界。
3. 用生活语言解释概念，不要写成教材、论文或自测题。
4. 语气温和但不空泛，避免“你太敏感”“你想太多”这种责备。
5. 结尾给一个能当天尝试的小动作，例如记录触发点、暂停刺激源、找可信任的人聊聊。
