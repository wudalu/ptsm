# Psychology Style

写现代心理困境观察内容时：

1. 标题只写一个具体瞬间、动作或脑内小剧场；不要在标题里写心理机制名，也不要用“不是 xxx，是 xxx”破梗。
2. 每篇只解释一个心理机制，例如反刍思维、低控制感、边界压力、情绪回避、比较焦虑；机制名放在场景之后，最多出现一次。
3. 结构遵循：具体瞬间 -> 场景继续推进 -> 一句轻机制 -> 可存句/小工具/小动作 -> 角色或阵营评论入口 -> 专业边界。
4. 用生活语言解释概念，不要写成教材、论文、自测题或心理课。
5. 语气温和但不空泛，避免“你太敏感”“你想太多”这种责备，也避免“不是你太敏感/不是你想太多”这种固定句式。
6. 工具型内容可以给事实/猜测/下一步三栏、5 分钟计时器、边界句模板、消息草稿、想法改写前后对照；故事型或角色型内容可以只给一句可存的话或一个当天能做的小动作。
7. 结尾用角色认领、A/B 阵营或填空问题，例如“你是哪派：A.写完秒删 B.发了秒后悔？”“今天让你脑补最多的一句是____”。不要只问“你怎么看？”
8. 选题轮换使用六个 lane，不要把所有内容都写成职场反刍：
   - 职场复盘 / 低控制感：会议复盘、18:57 在吗、下班消息把身体拉回工位
   - 亲密关系 / 不确定感：没回消息、忽冷忽热、暧昧要不要问清楚、分手脑补
   - 关系边界 / 消息压力
   - 数字生活 / 信息过载
   - 孤独 / 比较焦虑 / 社交耗竭：朋友圈高光、社交电量、约好的局临时不想去
   - 情绪调节 / 恢复练习
   - 睡眠恢复 / 轻养生 / 办公室恢复
   - 热点心理化重构
9. 睡眠恢复、轻养生和办公室恢复只作为心理学子线实验：写身体收口、下班信号、睡前降噪和 5 分钟低成本动作；不要写医疗养生建议、营养方案、治疗承诺或睡眠改善保证。
10. 热点心理化时优先借结构，不直接蹭词：`爱你老己` 写成非消费型自我关怀，`三明治拒绝法` 写成边界句工具，`丝瓜汤式沟通` 写成假性关心和无效沟通，AI 陪伴写清楚边界。
11. 如果目标是提高浏览、点赞或收藏，不要写运营话；把增长信号落成首屏具体瞬间、低密度可保存工具和角色/阵营/填空评论入口。
12. 命中忽冷忽热站队、社交电量取消局、下班消息身体警报时，分别给 `事实 / 信号 / 我要不要问清楚`、`取消局三句`、`下班消息三步`；不要退回泛职场复盘或泛边界句。
13. 正文目标 350-550 字，硬上限 580 字；少写解释，多写一个真实瞬间。
14. 小红书图文呈现要“平实贴图 + 少量文字”：优先把可保存工具做成 `iphone_notes` 低密度截图；单句重构可用 `note_card`；只有正文真的围绕消息对话、群聊或可复制回复时才用 `wechat_chat`。
15. 图片上最多放 1-3 个短文字单元，不放心理机制长解释、专业边界、话题标签或正文段落。
