# Psychology Style

写现代心理困境观察内容时：

1. 每篇只解释一个心理机制，例如反刍思维、低控制感、边界压力、情绪回避、比较焦虑。
2. 结构遵循：第一人称微场景 -> 心理机制 -> 非诊断化重构 -> 可保存小工具 -> 例子型评论 -> 专业边界。
3. 用生活语言解释概念，不要写成教材、论文或自测题。
4. 语气温和但不空泛，避免“你太敏感”“你想太多”这种责备。
5. 每篇给一个能当天尝试、适合截图保存的小工具，例如事实/猜测/下一步三栏、5分钟计时器、边界句模板、消息草稿、想法改写前后对照。
6. 结尾问读者一个具体例子，例如“你最容易反复复盘哪类瞬间？”不要只问“你怎么看？”
7. 选题轮换使用六个 lane，不要把所有内容都写成职场反刍：
   - 职场复盘 / 低控制感
   - 关系边界 / 消息压力
   - 数字生活 / 信息过载
   - 孤独 / 比较焦虑 / 社交耗竭
   - 情绪调节 / 恢复练习
   - 热点心理化重构
8. 热点心理化时优先借结构，不直接蹭词：`爱你老己` 写成非消费型自我关怀，`三明治拒绝法` 写成边界句工具，`丝瓜汤式沟通` 写成假性关心和无效沟通，AI 陪伴写清楚边界。
9. 小红书图文呈现要“平实贴图 + 少量文字”：优先把可保存工具做成 `iphone_notes` 低密度截图；单句重构可用 `note_card`；只有正文真的围绕消息对话、群聊或可复制回复时才用 `wechat_chat`。
10. 图片上最多放 1-3 个短文字单元，不放心理机制长解释、专业边界、话题标签或正文段落。
